# Bangladesh Directory — Registration & Email Verification

This integration package extends an existing Laravel 12 + React + Inertia + MySQL project. It includes the Phase 1 database foundation (migrations and models) plus the registration action, role seeder, React registration page, provider route protection example, and feature tests.

**Read `docs/INTEGRATION.md` before copying anything.** Back up your project and database first. Check `php artisan migrate:status` to avoid duplicate migrations. This is an integration package, not a standalone Laravel installation.
